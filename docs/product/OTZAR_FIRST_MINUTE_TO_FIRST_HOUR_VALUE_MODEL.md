# OTZAR First-Minute to First-Hour Value Model

**Date:** 2026-07-27  
**Status:** CONTRACT for experience + demo seeding  

## First minute

User understands without explanation:

| Signal | Surface |
|--------|---------|
| Who I am / org | Login + Today greeting |
| What needs me | Today needs band / Needs me count |
| What changed | Today changed band |
| What Otzar handled | Today handled / twin_work |
| What is connected | Tools chip honesty |

**Pass criteria:** no fixture flash; no synthetic coworkers; no competing Talk tabs.

## First five minutes

| Action | Evidence |
|--------|----------|
| Ask grounded question | Floating Talk → Work OS route or COE answer |
| Open real work | Needs me / project |
| See source or proof | ledger / execution attempt |
| Approve or correct | Action Center / Corrections |

## First fifteen minutes

communication → obligation → approval → execution → proof visible end-to-end.

## First hour

Cross-person handoff, AI Teammate contribution, notification, measurable coordination benefit (only if grounded counts exist).

## Anti-patterns

- Generic dashboard widgets  
- Developer essays  
- Fake time-saved numbers  
- Three Talk systems
